# 札幌・北海道 2027 旅行地圖

這個網站用來規劃 **2027 年 6 月 12 日至 18 日的北海道七天六夜旅行**。這趟旅行以札幌為住宿基地。出發前可比較行程與預算，旅途中可查當日景點、餐廳與伴手禮。

[開啟札幌・北海道旅行地圖](https://l49527.github.io/sapporo-travel-map/)

## 開始規劃

1. 在「選擇想要的北海道」選擇路線。A 為自然景觀，B 為海景美食，C 為舒適慢遊。
2. 選擇交通方案。可全程搭大眾運輸、租車 1 天或租車 2 天。
3. 在「七日旅行時間軸」選擇日期。查看該日行程、交通方式、餐廳與伴手禮。
4. 按「分享這一天」。開啟分享連結時，網站會套用同一條路線、租車天數與日期。

## 網站功能

| 功能 | 可以做什麼 |
| --- | --- |
| 每日行程 | 查看各日時間表、交通提醒與備選行程。可複製當日行程、匯出七日行程 JSON，或按「列印 / PDF」開啟瀏覽器的列印視窗。 |
| 互動地圖 | 查看北海道旅程路線與當日景點。在餐廳或伴手禮卡片按地圖按鈕，可查看建議前往的區域。 |
| 實景照片 | 瀏覽北海道景點照片與精選體驗。景點照片附來源與授權資訊。 |
| 餐廳與伴手禮 | 依日期查詢餐廳、建議購買地點與營業時間。卡片提供來源連結，部分卡片附照片。 |
| 札幌住宿 | 依路線篩選飯店。比較可住 3 位成人且面積至少 27 m² 的房型，並查看房內設施、洗衣方式與照片。 |
| 旅費預算 | 輸入人數與各項費用。以新臺幣查看全團總額與每人分攤。3 人同行時，可比較一間三人房與兩間房的住宿費用。 |
| 行前準備 | 依交通方案查看待辦事項。可勾選完成項目、新增個人待辦、匯出清單及匯入紀錄。網站也提供日本免稅資訊與官方查詢連結。 |

營業時間、交通班次、房價與空房以業者公告為準。出發或預訂前，請使用網站上的來源連結確認。

## 儲存與離線使用

- 預算與清單進度儲存在目前的瀏覽器。
- 第一次請連線開啟網站。瀏覽器完成快取後，離線時可開啟已快取的頁面與照片。
- 線上地圖、外部照片與外部連結需要網路。

## 本機預覽與維護

在專案目錄啟動本機伺服器。

```bash
python3 -m http.server 8000
```

[開啟本機預覽](http://localhost:8000/)

網站可直接部署到 GitHub Pages。在 **Settings → Pages** 選擇 `main` 分支與 `/ (root)`。保留 `.nojekyll` 與資源相對路徑。

維護時可執行 `npm test`。新增本機圖片時，同步更新 `sw.js` 的快取清單。
