# 天氣與穿搭

來源核對日期：2026-11-25。修改對象為 `L49527/sapporo-travel-map`，九州網站僅供讀取參考。

## 呈現與資料來源

每日行程中提供目的地選單、旅行當天的預報或六月行前參考、近期七天預報，以及衣物／裝備建議。地點隨 A/B/C 與租車方案更新；跨區日提供各主要目的地個別查詢，數值為所選地點附近的模式預報，不代表整條路線或山頂。

參考九州網站的 Open-Meteo 直接連線方式，選擇同一免費 API；無須後端、API Key 或定位權限。免費服務僅限非商業使用；現有私人行程網站適用。若將來有廣告、訂閱或其他商業用途，需重新評估方案。

## 日期與顯示規則

請求 `https://api.open-meteo.com/v1/forecast`，使用固定目的地經緯度、`timezone=Asia/Tokyo`、`forecast_days=16`、`temperature_unit=celsius`、`wind_speed_unit=ms`，取得每日天氣代碼、高低溫、降雨機率、最大風速與 UV。

旅行日期固定為 2027-06-12～18，必須與 API 的 `daily.time` 完全相符才顯示旅行當天預報。超過預報範圍、日期已過或缺少資料時顯示明確狀態與六月穿搭參考。近期七天另列實際日期及近期穿搭，與旅行當天分開。頁面時間均為日本時間；「資料擷取」是成功取得 API 回應的時間，不是氣象模式發布時間。

缺值維持未知，不以 0°C、0% 或晴天替代。WMO 80–82 為陣雨，85–86 為陣雪，只有 95、96、99 列為雷雨。降雨機率不推論雨勢大小。衣物建議由本站的規則產生，不是 Open-Meteo 或氣象廳官方穿衣指數；以高低溫、風、雨雪、UV 與地點補充用品，並標示個人體感差異。

## 連線與離線

`js/weather.js` 與 `css/weather.css` 隨網站預下載；天氣 JSON 另依地點存在 localStorage。30 分鐘內重用，同地點同時只送一個請求；手動更新也至少間隔一分鐘。8 秒逾時或連線失敗保留最多 24 小時的快取，顯示擷取時間與已儲存狀態；過期後只保留行前參考。無痕模式、儲存空間不足或 localStorage 不可用時，仍可在當次頁面載入天氣。

切換路線與地點會防止較慢的舊請求覆蓋新選擇。恢復連線、回到分頁或手動更新時再次檢查資料；分頁持續開啟時每 30 分鐘檢查一次，隱藏時不輪詢。API 失敗不影響行程、餐廳、地圖與預算。
