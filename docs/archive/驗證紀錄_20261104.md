## 進場動畫排查（左右進場）

### 現象與結論

- 使用者反映正式網站看不到左右進場動畫；本機 `http://127.0.0.1:8765/` 以瀏覽器實測**可以**正常播放（卡片由 `translateX(±100px)`、`opacity 0` 動畫到定位，約 550ms，延遲 100–400ms）。
- 因此程式邏輯本身沒有壞掉，差異只可能來自：部署時漏傳 `css/interaction-effects.css`、`js/interaction-effects.js`，瀏覽器／Service Worker 仍使用舊快取，或系統開啟「減少動態效果」。
- 為了讓上述原因可以自己一眼判斷，`js/interaction-effects.js` 現在會在 console 留下 `window.hokkaidoMotion` 診斷物件。

### 這次的改法

- 動畫開關由 CSS 媒體查詢改為 JS 加上 `html.motion-on`：`@media (prefers-reduced-motion: no-preference)` 在少數瀏覽器不會成立，會讓整段動畫規則失效；現在只要支援 `IntersectionObserver` 就會播放。
- 「減少動態效果」仍然完全尊重：JS 不加上 `motion-on`，且 CSS 保留 `prefers-reduced-motion: reduce` 的強制顯示規則。
- 進場範圍從原本 9 種卡片擴大為 17 種：新增 `.section-head`、`.budget-field`、`.prep-article`、`.brief-item`、`.fact`、`.refund-step`、`.checklist-timeline-row`、`.time-step`。
- 區塊標題改為由下方 44px 淡入（620ms）；故事區照片左 120px、文字右 120px（600ms）；其餘卡片依 `left / right / bottom` 循環並以 150ms 遞延。
- `css/interaction-effects.css` 與 `js/interaction-effects.js` 版本字串升為 `20261104-motion3`，`sw.js` 快取升為 `sapporo-travel-shell-v36`。

### 真正的原因：Service Worker 把舊 index.html 留在快取

- 本機重現了使用者的狀況：`sw.js` 已更新到 `v36`、快取裡的 `index.html` 也已是 `motion3`，但重新開啟頁面時瀏覽器仍載入 `interaction-effects.css?v=20261104-motion2`，且 `window.hokkaidoMotion` 不存在。
- 也就是說，畫面上跑的是**舊版 HTML**：它指向舊的 CSS／JS 網址，新檔案根本沒有被請求，所以看不到新的左右進場動畫。
- 清掉 Service Worker 與 `caches` 後重新載入，立刻變成 `motion3`，動畫恢復。這證明問題不在動畫程式，而在快取。
- 修正 `sw.js`：導覽請求（`req.mode === 'navigate'`）改用 `fetch(req.url, {cache:'reload'})` 直接跳過 HTTP 快取，且執行時不再把 HTML 寫回快取；只有圖片、CSS、JS 仍走網路優先並更新快取。
- 離線時才退回預先快取的 `index.html`，因此斷網仍可開啟頁面。

### 瀏覽器驗證

- `html.motion-on` 存在、`window.hokkaidoMotion.enabled === true`、`reducedMotion === false`。
- 8 個 `.section-head` 全部由 `opacity 0 / translateY(44px)` 進場；`.tour-card`、`.dd-pick`、`.gallery-shot`、`.budget-field`、`.prep-article`、`.time-step` 亦同。

### 若正式網站仍沒有動畫

1. 開啟網站後按 F12 → Console，輸入 `window.hokkaidoMotion` 並按 Enter。
2. 出現 `undefined`：`js/interaction-effects.js` 沒有上傳或被快取擋住，重新上傳該檔與 `index.html`。
3. 出現物件但 `enabled: false`：系統「減少動態效果」是開啟的（macOS：系統設定 → 輔助使用 → 顯示器）。
4. 出現 `enabled: true` 但畫面沒有動：`css/interaction-effects.css` 沒有載入，或 HTML 仍指向舊版本，重新上傳 `css/interaction-effects.css` 與 `index.html`。
5. 最後在 DevTools → Application → Service Workers 按「Update」或「Unregister」，再強制重新整理。
